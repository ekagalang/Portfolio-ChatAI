Next.js 16 App Router portfolio site for Eka Galang Pratama with AI/chat features and contact/GitHub integrations. Tech stack: Next.js 16, React 19, TypeScript, Tailwind CSS v4 via @tailwindcss/postcss, Geist fonts, Framer Motion. Important structure: src/app for app routes/layout/globals, public for static assets, Dockerfile and docker-compose.yml for production deployment. next.config.ts sets output="standalone".
